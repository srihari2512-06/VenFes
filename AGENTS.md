# AGENTS.md

## Ponytail Rules for Antigravity & LLM Agents
1. Read project.md, prd.md, srs.md, skill.md before writing code.
2. The best code is the code never written. Solve the whole problem with the least new code.
3. Ladder: (1) Does it need to exist? (2) In repo? (3) Stdlib? (4) Native? (5) Installed dep? (6) One line? (7) Minimum working code.
4. Never cut validation at trust boundaries, data-loss error handling, security, or accessibility.
5. Provide tests or self-checks for non-trivial logic.
6. End replies with what was skipped or unverified, and known risks.
